# QuaiVault — Некастодиальный кошелек QI и QUAI, UTXO-инспектор и конвертер (Cyprus-1)

**QuaiVault** — открытое некастодиальное веб-приложение и десктопный терминал для Windows 10/11 для работы с кошельками **QI (UTXO)** и **QUAI (EVM)** в основной сети **Quai Network (шард Cyprus-1, `0x00`)**.

Сервис полностью обезличен для публичного использования: **приватные ключи, сид-фразы и адреса кошельков никогда не сохраняются** на диск, в базу данных или `localStorage`.

---

## Основные возможности

1. **Открытие кошелька QI и обход ошибки `BIP44 derivation path`**
   * Решает ошибку Pelagus / `quais` SDK: `Address 0x00... already exists in BIP44 derivation path` за счет инициализации изолированного контейнера `QiHDWallet` и детерминированных адресов сдачи.
   * Сканирует все UTXO-выходы (`quai_getOutpointsByAddress`), разделяя средства на **Доступные сейчас (Unlocked)** и **Находящиеся в 2-недельной разблокировке майнинга (Locked, 241 920 блоков)**.
   * Строит таблицу распределения по номиналам купюр QI и посуточный график разморозки майнинга.

2. **Отображение баланса в 4 валютах (QI, QUAI, USD `$` и RUB `₽` по курсу ЦБ РФ)**
   * Автоматическое получение биржевого курса `QUAI/USD` (Gate.io / CoinGecko), протокольного курса конвертации `quai_qiToQuai` из узла Cyprus-1 и официального курса доллара **ЦБ РФ (`cbr-xml-daily.ru`)**.

3. **Расшифровка кошелька QUAI и конвертация `QUAI → QI`**
   * Поддержка 3 способов открытия кошелька: **Приватный ключ (`0x...`)**, **Мнемоническая фраза BIP-39 (12 или 24 слова)** с одновременным вычислением парного QI-адреса, а также **Web3 Keystore JSON + пароль**.
   * Экспорт любого приватного ключа в зашифрованный файл `Keystore JSON`.
   * Отправка `QUAI → QUAI` и протокольная конвертация `QUAI → QI` (если указать получателем QI-адрес со вторым байтом `>= 0x80`, протокол Quai автоматически конвертирует QUAI в UTXO-купюры QI).

4. **Встроенный протокольный конвертер `QI → QUAI`**
   * Формирует корректный 22-байтный `data` payload (`params.MaxQiTxDataLength = 22` в `go-quai`: 2 байта `slippage` + 20 байт Qi-адреса возврата) и уникальные детерминированные адреса сдачи, предотвращая ошибку `emits UTXO with To address not in the Qi ledger scope`.
   * Режим предпросмотра и расчета комиссии без отправки в сеть (**Dry-Run**) и отправка в Mainnet (**Broadcast**).

5. **История операций кошелька и поиск по `explorer.qu.ai`**
   * Отображение списка последних транзакций по адресу кошелька (`QUAI` или `QI`) со статусами (**Успешно**, **В ожидании**, **Ошибка**), автообновлением через RPC (`quai_getTransactionReceipt`) и прямыми ссылками на `https://explorer.qu.ai/`.

## Инструкция по запуску на Windows (Без VPS-сервера)

Для личного использования на домашнем компьютере с Windows **VPS-сервер не нужен** — приложение работает локально на `127.0.0.1:3000` и обращается напрямую к официальному RPC-узлу `https://rpc.quai.network/cyprus1`.

### Способ 1: Быстрый запуск через установщик `.bat` (Рекомендуется)
1. Скачайте файл [`QuaiVault-Windows-GUI-Installer.bat`](./public/downloads/QuaiVault-Windows-GUI-Installer.bat).
2. Запустите его двойным кликом на Windows 10 или Windows 11.
3. Если на компьютере еще не установлен **Node.js**, скрипт автоматически скачает официальный установщик `Node.js v20 LTS (.msi)` с `nodejs.org` и установит его.
4. На Рабочем столе создастся папка `QuaiVault-Desktop`, установятся зависимости `quais` и `express`, и автоматически откроется графическое окно кошелька по адресу `http://127.0.0.1:3000`.

### Способ 2: Запуск полной React + TypeScript версии из репозитория GitHub
1. Установите [Node.js v20+ LTS](https://nodejs.org/).
2. Склонируйте репозиторий или скачайте ZIP-архив с GitHub:
   ```bash
   git clone https://github.com/<ВАШ_ЛОГИН>/quaivault-wallet.git
   cd quaivault-wallet
   ```
3. Установите зависимости и запустите сервер:
   ```bash
   npm install
   npm run dev
   ```
4. Откройте в браузере `http://localhost:3000`.

## Развертывание на Ubuntu VPS (для публичного доступа)

## Безопасность и приватность

* **Zero Storage**: Серверные маршруты (`/api/wallet/*`) обрабатывают криптографические операции исключительно в оперативной памяти на время HTTP-запроса и не ведут логов приватных ключей.
* **Прямая работа с Quai Mainnet**: Все транзакции подписываются официальным SDK `quais` (`v1.0.0-alpha.53`) и отправляются напрямую в узел `https://rpc.quai.network/cyprus1`.
* **Интеграция с эксплорером**: Все хэши транзакций, блоки и адреса имеют прямые ссылки на официальный обозреватель `https://explorer.qu.ai/`.
